## 2. 赛事与赛道

### 2.1 赛事一句话

面向 AI for Science 的核心算子与科学计算模型：在壁仞 **BIREN GPU** 上，用 **AI Skills / Agent** 辅助，做出可运行、可验证、可复现的算子与模型。每人/每队只报一个赛道；作品默认上架 **SCP 广场** 参与社区投票。赛程壳层（海选 → 审核 → 投票 → 复赛 → 线下黑客松）以官网为准。

### 2.2 赛道结构（必须讲清）

本赛道 = **1 道必选题 + 3 道进阶题（三选一）**。两道题不能互相顶替。

| 题目 | 官方名称 | 我们选了吗 |
|------|----------|------------|
| **必选** | Spectral Convolution（FNO 核心 2D 谱卷积） | **是** |
| 进阶 A | PINN 求解二维稳态热传导 | 否 |
| 进阶 B | GNN 分子性质预测（QM9） | 否 |
| **进阶 C** | FNO 求解二维 Navier-Stokes 涡度方程 | **是** |

官网 FAQ：进阶 C 可以不用必选算子，但**复用必选算子有衔接加分**。我们正式叙事必须强调：FNO 推理复用同一套 SUPA SpectralConv，不是另写一套 `torch.fft`。

### 2.3 赛道特色（必须项，约 15 分）

不是「用了 ChatGPT 就算」。官方要求：

- 用壁仞自研 Agent **或** 通用工具（Cursor / Claude Code 等）辅助开发
- 提交交互日志或截图，**至少 5 段有效记录**，否则整份作品不合格
- 场景至少覆盖下列 6 类中的 **3 类**：kernel 设计调试；模型/超参；数据预处理；性能瓶颈；结果可视化；BIREN 平台适配
- 看深度、效率提升和工程判断，不是流水账

我方对应：`skill.md`（必须文件名）+ `AGENT_OFFICIAL.md`（评委抽查）+ `development_log.md`（全文）+ `agent_logs/`（对话原文与截图）。

### 2.4 实现路线（官方点名）

| 路线 | 含义 | 我们 |
|------|------|------|
| 方式一 | SUPA/C++ 直连，算子串联 | 仅 GEMV 模板验证过，正式作品不用 |
| **方式二** | `torch.extension`（C++/SUPA）封装，Python 组装模型 | **正式路线** |
| 禁止当正式实现 | 只拼原生 PyTorch / `torch.fft` 交差 | 红线 |

硬件：首选壁仞 BIREN；本队实测 **Biren106B 单卡**，设备名 `supa`（先 `import torch_br`），SDK `1.11.0.0.rc2`。不要求多卡。`torch.cuda.is_available()==False` 是平台预期。

## 3. 必选题：Spectral Convolution

**计算流程（上屏用）：**  
输入 `[B, C_in, H, W]` → FFT 到频域 → 低频 modes 上的可学习复数乘（双角）→ IFFT → `[B, C_out, H, W]`。

| 官方基础要求 | 我们怎么对上 |
|--------------|--------------|
| 2D 前向 | `spectral_conv/` SUPA + Extension |
| shape `[B,Cin,H,W] → [B,Cout,H,W]` | 正式评测 `B=4, Cin=32, Cout=64, modes=16` |
| 可配置 modes | `modes1/modes2` |
| 壁仞 GPU 上跑 | Biren106B / `supa` |
| 相对误差 ≤ 1e-4 | 最差 **2.170×10⁻⁷** |

| 官方加分项 | 我们 |
|------------|------|
| Backward | 已做，worst grad rel ≈ 6.25×10⁻⁸ |
| 3D 四角 | 已做，worst rel ≈ 1.19×10⁻⁷ |
| 64/128/256 性能报告 | 正式 idle **0.599 / 1.405 / 5.099 ms**（`pinned_src_r1` · v13） |
| Agent 过程 | 见必须项材料 |

**必选题评分（官网）：**

| 维度 | 权重 | 说明 |
|------|------|------|
| 正确性 | 35% | 相对误差 ≤ 1e-4 |
| 性能 | 25% | 执行时间、显存 |
| 代码质量 | 10% | 可读、模块化、SUPA/extension |
| Agent 开发 | 15% | 必须提交 |
| 扩展能力 | 15% | 3D、反向等 |

正片只报上述正式 idle。2026-08-15 裁剪 DFT 非正式计时（约 1.069 / 2.331 / 7.957 ms）**不进正片**。

## 4. 进阶题 C：FNO-NS

**求解目标：** 给定较早时刻涡度，预测下一时刻涡度。官网示例是 ω₀ → ω_T；我们正式协议是公开 NS64 **前 10 帧 → 第 11 帧**。

| 官方基础要求 | 我们 |
|--------------|------|
| ≥4 层 Fourier Layer | **4 层**，width=32，modes=16 |
| 复用必选 SpectralConv | 推理走同一套 fused 算子 |
| 公开 NS 64×64 粘度数据 | `navier_stokes_v1e-3_N1200_T20.pt`，**未改文件** |
| 报告相对 L2 | **0.035012**（v10 · `spec_ref_r2`） |
| 壁仞上搭建与推理 | 是；训练主路径在 CPU 可微旁路（加分项已做完训练） |
| 可视化 pred vs GT | `demo/media/01_典型样本_预测与真值.png`、`02_最好_典型_最差.png` |

划分与种子（必须与材料一致）：训练 **1000** / 测试 **128**，seed **20260722**。刚接官方集时 L2 **0.041835**。自建集 0.005144 **禁止当公开分**。

**进阶 C 评分（官网）：**

| 维度 | 权重 | 说明 |
|------|------|------|
| 精度 | 25% | 相对 L2，越低越好 |
| 模型搭建 | 30% | 结构完整、与必选算子衔接 |
| 性能 | 10% | 训练/推理（加分） |
| 可视化 | 20% | 流场对比 |
| Agent 开发 | 15% | 必须提交 |

选手手册补充验收：不少于 4 层 Fourier；64×64 NS；报告 L2 并可视化。手册里 PINN「L2≤1%」**不是** FNO-NS 的门槛，不要写到 FNO 页。
