# P7 + P8b · dual-corner launch + safe packed scale · 2026-07-29

## Changes
1. **P7**: `spectral_mul_gather_scatter_dual_kernel` — both corners in one launch
   (was two R11 launches). Mul ROI already tiny; small wall-clock help.
2. **P8 (bad)**: `col_out.mul_(1/(H*W))` on **stage-cached** C2C buffer → multi-call
   poison (call1 OK, call2+ rel≈1.24). Same class as cached C2R out.
3. **P8b (KEEP)**: scale on **fresh** `permute().contiguous()` buffer before pad
   copy; skip spatial `out.mul_`. Packed elems ≪ `B*C*H*W`.

## Lesson
Never `mul_` / mutate stage-cached FFT buffers in place; scale only fresh tensors
or bake into writers that fully overwrite outputs each call.
