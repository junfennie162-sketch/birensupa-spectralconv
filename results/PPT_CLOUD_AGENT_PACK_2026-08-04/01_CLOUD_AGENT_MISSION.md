# 云端 Agent 任务说明书

## 1. 角色

你是答辩 PPT 设计师 + 技术内容编辑。你**没有**访问队伍源码仓库的权限；本 ZIP 内 Markdown 即为全部上下文。不得臆造未给出的指标、未做过的实验或未声明的加速比。

## 2. 目标受众

- 主受众：赛道评委（3–10 分钟抽查 / 答辩）  
- 次受众：技术评委可能打开仓库复核数字与命令  
- 假设评委熟悉：深度学习 / PDE / GPU 算子；不假设熟悉壁仞 SDK 细节  

## 3. 必须交付

| 项 | 要求 |
|----|------|
| 页数 | **10–12 页**（推荐 11 页，见内容规范） |
| 画幅 | **16:9**（1280×720 或 1920×1080） |
| 格式 | 原生可编辑 **PPTX** 优先；否则 PDF |
| 内容覆盖 | 必选算子 + 进阶 FNO + Agent 必须项 + 可视化 + 失败诚实 + 复现入口 |
| 数字 | 与 `04_FROZEN_METRICS.md` **逐字一致**（圆整规则见该文件） |
| 官方对齐 | 页结构映射官方评分轴（见 `02` / `05`） |

## 4. 明确不做

- 不重新训练、不改指标、不编新版本号（无 v9）  
- 不把旁注探针（PF / Autopsy / r10）写成正式主报  
- 不把 SOL / proxy 写成官方得分  
- 不写「已超越竞品 GPU」「世界第一」等无依据话术  
- 不生成与冻结稿冲突的「下一步继续刷精度」路线（精度线已永久停）
