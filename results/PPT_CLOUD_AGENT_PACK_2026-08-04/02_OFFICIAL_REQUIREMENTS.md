# 官方规范对齐（赛道五 · 模型与算子）

> 依据：官网「赛道五 · 基于 Agent 的模型和算子开发」统一要求 / 提交规范 / 各题评测标准；  
> 及《算子与模型赛道选手手册》最低提交物与目录要求。  
> **PPT 本身是「展示材料」建议项，但页内容必须服务官方硬评分轴，不得跑题。**

---

## 1. 赛道结构（必须在 PPT 写清）

| 题型 | 本队选择 | 硬性 |
|------|----------|------|
| 必选题 | Spectral Convolution | **必须完成** |
| 进阶题 | **进阶 C · FNO-NS**（三选一已选定） | 必须完成所选进阶 |
| Agent/Skills | Cursor Agent 辅助开发 | **必须提交**；缺失不合格 |

官方表述要点：

- 必选算子核心必须用 **SUPA** 或 **torch.extension**，禁止只用原生 PyTorch 冒充正式实现。  
- 模型题应复用 / 衔接必选算子，不建议纯原生拼接。  
- 首选壁仞 **BIREN GPU** 单卡验证；不要求多卡。  

---

## 2. 必选题 · Spectral Convolution — 官方要求

### 2.1 基础要求（必须）

- 实现 2D Spectral Convolution **前向**  
- 输入 `[B, C_in, H, W]` → 输出 `[B, C_out, H, W]`  
- 可配置傅里叶模态截断 `modes`  
- 与 PyTorch reference 对比，**相对误差 ≤ 1e-4**  
- 在 BIREN 上运行  

### 2.2 进阶加分（本队已做，PPT 应点到）

- Backward  
- 3D Spectral Convolution（四角路径；**≠** 完整 3D FNO）  
- 性能优化与多分辨率报告（64 / 128 / 256）  
- Agent 辅助过程展示  

### 2.3 必选题评分权重（官网）

| 维度 | 权重 | PPT 应对齐的展示点 |
|------|-----:|-------------------|
| 正确性 | **35%** | rel≤1e-4；本队 worst≈2.17e-7 |
| 性能 | **25%** | 64/128/256 idle ms + 显存 |
| 代码质量 | **10%** | SUPA/Extension、模块化、可复现 |
| Agent 开发 | **15%** | 日志深度与工程判别 |
| 扩展能力 | **15%** | Backward / 3D / irregular 等 |

---

## 3. 进阶 C · FNO-NS — 官方要求

### 3.1 基础要求

- 基于必选 SpectralConv 搭建完整 FNO，**≥ 4 层** Fourier Layer  
- 使用公开 Navier-Stokes 2D **64×64** 粘度数据集  
- 报告**相对 L2**  
- BIREN 上搭建与推理验证（训练为加分，非硬性）  
- **可视化**预测流场 vs ground truth  

### 3.2 进阶 C 评分权重（官网）

| 维度 | 权重 | PPT 应对齐的展示点 |
|------|-----:|-------------------|
| 精度 | **25%** | 公开 NS64 相对 L2（本队 0.035302） |
| 模型搭建 | **30%** | 4 层 + 复用必选算子 |
| 性能 | **10%** | 推理/训练吞吐（加分旁注即可） |
| 可视化 | **20%** | Pred / GT / error 图 |
| Agent 开发 | **15%** | 同必须项 |

## 4. 统一提交规范（官网）

### 4.1 必须提交

1. 项目源码（SUPA / Extension）  
2. 完整依赖说明与编译 / 运行命令  
3. 正确性验证脚本与结果  
4. 性能测试脚本与报告  
5. 运行日志或截图（BIREN 单卡）  
6. **Agent/Skill 开发日志 ≥ 5 段有效交互**（缺失无效）  
7. **`skill.md`（必须）**  

### 4.2 建议提交（展示材料）

- PPT / 视频 / 可视化图片 — **可选但强烈建议**  
- 本任务即补齐建议项中的 PPT  

### 4.3 Agent 场景覆盖（至少 3 类）

官网列出的场景池（至少覆盖 3 项）：

1. 算子 kernel 设计 / 调试 / 优化  
2. 模型架构选型与超参搜索  
3. 数据预处理与特征工程  
4. 性能瓶颈分析与定位  
5. 结果分析与可视化代码生成  
6. BIREN GPU 平台适配问题排查  

本队日志已覆盖上述多类；PPT Agent 页应写明「≥5 段 · ≥3 类 · 工具=Cursor」。

### 4.4 运行要求

- 必须：可运行的模型前向，BIREN 单次推理验证  
- 不要求多卡 / 分布式  
- 训练建议 <2h 或提供 checkpoint  
- 完整评测脚本建议 <30 min  

### 4.5 手册目录最低结构（评委可能对照）

```
submission/
├── README.md
├── build.sh 或 Makefile
├── kernel/extension 源码
├── test 脚本
├── results.md
├── development_log.md
├── skill.md
└── 可选：PPT、图、checkpoint
```

## 5. PPT 与官方评分的映射（设计强制）

云端 Agent 生成的 PPT **每一页必须能回答「对应哪条官方权重」**：

| PPT 主题块 | 主要服务的官方轴 |
|------------|------------------|
| 选题与架构 | 模型搭建 30% + 代码质量 |
| 正确性 / 误差 | 必选正确性 35% |
| 性能三档 ms | 必选性能 25% |
| 扩展 backward/3D | 扩展 15% |
| FNO L2 + 配方 | 进阶精度 25% + 搭建 30% |
| 流场可视化 | 进阶可视化 20% |
| Agent / skill | Agent 15%（必选+进阶共用） |
| 失败与门禁 | 工程深度（服务 Agent / 代码质量印象） |
| 复现命令 | 可复现性（提交规范） |
