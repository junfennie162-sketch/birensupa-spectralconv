## 1. 总叙事（金字塔）

1. **结论先行**：我们在 Biren 单卡上完成必选 SpectralConv + 进阶 FNO，主报 L2=0.035302，idle 三档冻结。  
2. **证据**：正确性远低于 1e-4；性能表；流场图；扩展三测。  
3. **过程**：Agent 驱动迭代 + 失败诚实回滚。  
4. **可复现**：命令三行。  
5. **边界**：精度永久停；不吹 SOL。

## 3. 60 秒性能专项（若被追问）

1. mul 已噪声级（≈0.23 ms）；墙在 C2R/FFT。  
2. formal 三档冻结；对外讲 vs 官网 CPU ≈19.5×/11.1×/10.0×（**旁注，不是 SOL**）。  
3. 显存 225/253/353 MB；融合=设备常驻+稀疏 scatter，**不是** SDK 级 FFT⊗mul 真融合。
